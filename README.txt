BORROWER LEDGER PWA

INSTALLATION
1. Extract this ZIP to a folder.
2. Host all files together on an HTTPS website. PWA installation and service workers do not reliably work when index.html is opened directly as a local file.
3. Open the HTTPS link in Chrome or Edge on Android, or Safari on iPhone.
4. Android: use Install App / Add to Home Screen. iPhone: Share > Add to Home Screen.

FEATURES
- Offline use after first successful online load
- Borrower master with edit/delete
- Lent and repaid transactions with edit/delete
- Receipt photo attachment stored locally
- Interactive borrower and monthly analytics
- WhatsApp reminder link
- Local PIN and dark mode
- JSON backup/restore and Excel-compatible CSV export

LIMITATIONS
- Data and PIN are local to the selected browser profile. The PIN is an access deterrent, not encryption.
- Receipt photos increase browser storage usage.
- True automatic OneDrive/Google Drive sync requires creating and configuring a cloud app registration with OAuth credentials. This generic package instead lets you download a backup and save/share it to OneDrive or Google Drive.
- Automatic backups cannot run while the browser/app is closed.
